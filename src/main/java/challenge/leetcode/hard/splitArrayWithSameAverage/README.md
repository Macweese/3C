# 805. Split Array With Same Average

<h3 style="color:#FF4800;">Hard</h3>

## Description

<p>You are given an integer array <code>nums</code>.</p><p>You should move each element of <code>nums</code> into one of the two arrays <code>A</code> and <code>B</code> such that <code>A</code> and <code>B</code> are non-empty, and <code>average(A) == average(B)</code>.</p><p>Return <code>true</code> if it is possible to achieve that and <code>false</code> otherwise.</p><p><strong>Note</strong> that for an array <code>arr</code>, <code>average(arr)</code> is the sum of all the elements of <code>arr</code> over the length of <code>arr</code>.</p>
