# 2769. Find the Maximum Achievable Number

<h3 style="color:#3BE38C;">Easy</h3>

[LeetCode 2769](https://leetcode.com/problems/find-the-maximum-achievable-number/)

## Description

<p>Given two integers, <code>num</code> and <code>t</code>. A <strong>number </strong><code>x</code><strong> </strong>is<strong> achievable</strong> if it can become equal to <code>num</code> after applying the following operation <strong>at most</strong> <code>t</code> times:</p><ul>
<li>Increase or decrease <code>x</code> by <code>1</code>, and <em>simultaneously</em> increase or decrease <code>num</code> by <code>1</code>.</li>
</ul><p>Return the <strong>maximum </strong>possible value of <code>x</code>.</p>

#### Example 1
<div style="margin-left: 40px">

<b>Input:</b>
<pre style="margin-left: 40px">
<span class="example-io">num = 4, t = 1</span>
</pre>

<b>Output:</b>
<pre style="margin-left: 40px">
<span class="example-io">6</span>
</pre>

<b>Explanation:</b>
<pre style="margin-left: 40px">
<p>Apply the following operation once to make the maximum achievable number equal to <code>num</code>:</p><ul>
<li>Decrease the maximum achievable number by 1, and increase <code>num</code> by 1.</li>
</ul>
</pre>

</div>

<br>
