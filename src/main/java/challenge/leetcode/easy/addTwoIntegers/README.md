# 2235. Add Two Integers

<h3 style="color:#3BE38C;">Easy</h3>

[LeetCode 2235](https://leetcode.com/problems/add-two-integers/)

## Description

Given two integers `num1` and `num2`, return _the **sum** of the two integers_.

<br>


#### Example 1
<div style="margin-left: 40px">

<b>Input:</b>

<div style="margin-left: 40px">

`num1 = 12, num2 = 5`
</div>

<b>Output:</b>

<div style="margin-left: 40px">

`17`
</div>

<b>Explanation:</b>

<div style="margin-left: 40px">

num1 is 12, num2 is 5, and their sum is 12 + 5 = 17, so 17 is returned.
</div>
</div>


#### Example 2
<div style="margin-left: 40px">

<b>Input:</b>

<div style="margin-left: 40px">

`num1 = -10, num2 = 4`
</div>

<b>Output:</b>

<div style="margin-left: 40px">

`-6`
</div>

<b>Explanation:</b>

<div style="margin-left: 40px">

num1 + num2 = -6, so -6 is returned.  
</div>
</div>

### Constraints:

* <code>-100 &le; num1, num2 &le; 100</code>

<br>
