# 3701. Compute Alternating Sum

<h3 style="color:#3BE38C;">Easy</h3>

[LeetCode 3701](https://leetcode.com/problems/compute-alternating-sum/)

## Description

<p>You are given an integer array <code>nums</code>.</p><p>The <strong>alternating sum</strong> of <code>nums</code> is the value obtained by <strong>adding</strong> elements at even indices and <strong>subtracting</strong> elements at odd indices. That is, <code>nums[0] - nums[1] + nums[2] - nums[3]...</code></p><p>Return an integer denoting the alternating sum of <code>nums</code>.</p>

#### Example 1
<div style="margin-left: 40px">

<b>Input:</b>
<pre style="margin-left: 40px">
<span class="example-io">nums = [1,3,5,7]</span>
</pre>

<b>Output:</b>
<pre style="margin-left: 40px">
<span class="example-io">-4</span>
</pre>

<b>Explanation:</b>
<pre style="margin-left: 40px">
<ul>
<li>Elements at even indices are <code>nums[0] = 1</code> and <code>nums[2] = 5</code> because 0 and 2 are even numbers.</li>
<li>Elements at odd indices are <code>nums[1] = 3</code> and <code>nums[3] = 7</code> because 1 and 3 are odd numbers.</li>
<li>The alternating sum is <code>nums[0] - nums[1] + nums[2] - nums[3] = 1 - 3 + 5 - 7 = -4</code>.</li>
</ul>
</pre>

</div>

<br>

#### Example 2
<div style="margin-left: 40px">

<b>Input:</b>

</pre>

<b>Explanation:</b>
<pre style="margin-left: 40px">
<ul>
<li>The only element at even indices is <code>nums[0] = 100</code> because 0 is an even number.</li>
<li>There are no elements on odd indices.</li>
<li>The alternating sum is <code>nums[0] = 100</code>.</li>
</ul>
</pre>

</div>
